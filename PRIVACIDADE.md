# Política de privacidade

Última atualização: 3 de novembro de 2026

Este aplicativo é uma ferramenta pessoal usada pelo dono dos canais do YouTube "Mente Curiosa" e
"Manhwa News BR" para enviar e agendar os próprios vídeos pela API de Dados do YouTube.

## Dados acessados

- Com a autorização do dono do canal, o aplicativo usa a API do YouTube apenas para: identificar o
  canal autorizado, enviar vídeos, definir a data de publicação e a thumbnail.
- Não lê, coleta, armazena nem compartilha dados de outros usuários, espectadores ou comentários.

## Armazenamento

- O token de acesso fica guardado apenas como variável de ambiente privada, sob controle do dono do canal.
- Nenhum dado é vendido, compartilhado com terceiros ou usado para publicidade.

## Revogar o acesso

O acesso pode ser revogado a qualquer momento em https://myaccount.google.com/permissions.

O uso de dados da API do YouTube segue os Termos de Serviço do YouTube (https://www.youtube.com/t/terms)
e a Política de Privacidade do Google (https://policies.google.com/privacy).
